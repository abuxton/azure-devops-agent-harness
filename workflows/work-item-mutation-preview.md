# Work-item mutation preview

Before any work-item mutation, provide:

- selected profile, organization, project, and work-item identifier;
- current and proposed field values;
- linked work items;
- agent rationale and evidence;
- expected Azure DevOps effect;
- explicit user confirmation outcome;
- resulting revision or failure details.

After confirmation, request a separate VS Code allow decision for the MCP tool call and write the result to `audit/`.
